# 需求：今日总结收藏 + 收藏夹 AI 自动分类

## 日期
2026-10-13

## 背景
用户提出三个待实现需求：
1. 今日总结（核心结论/重点关注/行业作用/风险提示）也支持收藏
2. 收藏夹需要分类功能，帮助用户快速找到需要的信息
3. 未登录用户点击任何位置的收藏按钮都应弹出登录

## 方案
1. **总结收藏**：整个总结卡片添加一个 ☆ 按钮，收藏整篇总结（URL 为 `summary://日期`）
2. **AI 自动分类**：收藏时根据 source + title + brief 的关键词匹配自动归类为 5 类：
   - 🔧 工具/框架
   - 🤖 模型/算法
   - 📊 行业趋势（默认）
   - 💡 灵感/案例
   - 📚 学习/方法
3. **未登录弹登录**：已由全局 click handler 覆盖，总结按钮自动遵循

## 改动文件
- `scripts/build_site.py`：render_summary() 增加 fav-btn + 日期参数；favorites 页面增加 fav-categories 容器
- `docs/fav.js`：autoCategorize() 函数 + 分类 tab + 分类标签显示 + 兼容旧数据
- Supabase：favorites 表新增 category 列

## 验收标准
- [x] 首页总结卡片右侧有 ☆ 按钮
- [x] 未登录点击总结 ☆ → 弹出登录弹窗
- [x] 登录后收藏总结 → 收藏夹显示「今日总结 · 日期」
- [x] 收藏条目自动归类
