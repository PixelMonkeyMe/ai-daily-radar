# AI 日报雷达

每天自动汇聚 GitHub 趋势项目、Hacker News AI 热帖、HuggingFace 热门模型、国内 AI 新闻，
由 Kimi 按固定五段式格式生成中文解读，发布成一个随时随地可打开的网页。

**解读格式（每条资讯）**：这是什么？→ 对我的行业（智慧交通/智慧高速/智慧消防/施工成本管控）有什么用？→ 这能干什么？→ 评估与判断 → 风险与应用场景

---

## 部署教程（零基础，全程约 20 分钟，只需点鼠标）

### 第 1 步：注册 GitHub 账号
打开 https://github.com → 点 Sign up → 用邮箱注册（免费）。

### 第 2 步：创建仓库
1. 登录后点右上角 **+** → **New repository**
2. Repository name 填：`ai-daily-radar`
3. 保持 **Public**（公开），其他不用动，点 **Create repository**

### 第 3 步：上传本项目文件
1. 在新仓库页面点 **Add file** → **Upload files**
2. 把本项目文件夹里的**所有内容**（包括 `.github`、`scripts`、`requirements.txt` 等）整体拖进网页
   - 注意：`.github` 文件夹也要拖进去，网页可能会提示，确认即可
3. 点底部绿色按钮 **Commit changes**

### 第 4 步：申请 Kimi API 密钥
1. 打开 https://platform.moonshot.cn → 手机号注册登录
2. 左侧菜单 **API Key 管理** → **新建 API Key** → 复制保存（只显示一次）
3. 左侧 **充值** 充 10 元即可（每天一份日报约几分钱，够用很久）

### 第 5 步：把密钥存进仓库（Secret）
1. 回到 GitHub 仓库 → 顶部 **Settings** → 左侧 **Secrets and variables** → **Actions**
2. 点 **New repository secret**
3. Name 填：`MOONSHOT_API_KEY`，Secret 粘贴刚才的密钥 → **Add secret**

### 第 6 步：开启网页发布（GitHub Pages）
1. 仓库 **Settings** → 左侧 **Pages**
2. Source 选 **Deploy from a branch**
3. Branch 选 **main**，文件夹选 **/docs** → **Save**
   - 注意：/docs 文件夹要等第 7 步运行一次后才会出现；如果还没有，先跳过本步，运行完再回来设置

### 第 7 步：手动运行第一次
1. 仓库顶部 **Actions** 页签 → 如有提示点 **I understand... enable them**
2. 左侧点 **AI 日报雷达** → 右侧 **Run workflow** → 绿色 **Run workflow**
3. 等 2-3 分钟变成绿色对勾，说明成功

### 第 8 步：收藏你的日报网址
```
https://<你的GitHub用户名>.github.io/ai-daily-radar/
```
把这个网址**收藏到手机浏览器和电脑浏览器**——以后每天早上 9 点后打开就是最新日报，
历史日报在页面底部可翻。

## 常见问题

**Q：怎么收藏资讯？**
每条资讯标题旁有一个 ☆，点一下变 ★ 就是收藏了，再点一下取消。日报页、历史日报、周期汇总里的条目都可以收藏。

**Q：收藏夹在哪里？手机电脑能同步吗？**
页面顶部导航点 **"我的收藏夹"**。收藏夹支持按日期排序和关键词模糊查询。
收藏无需登录：收藏夹页顶部会生成一个**专属链接**，把它**存为书签**或**发到自己微信/文件传输助手**，任何设备打开这个链接就能看到收藏。
注意：在别的设备上新增收藏后，链接会更新，需要把新链接重新保存一次。

**Q：周报/月报/季报在哪里看？**
日报首页顶部点 **"周期汇总（周/月/季）"**。周报每周一生成，月报每月 1 号生成，季报每季度首月 1 号生成，全部自动。

**Q：想自己选时间区间汇总怎么办？**
仓库 → **Actions** → 左侧 **周期汇总（周报/月报/季报）** → 右侧 **Run workflow**：
- 想快速出周报/月报/季报：选好类型直接点 Run workflow
- 想自定义区间：类型选 **custom**，填入开始/结束日期（如 2026-09-01 到 2026-09-21），点 Run workflow
等 2-3 分钟后到"周期汇总"页面的"自定义汇总"分组里查看。

**Q：周期汇总里有什么？**
本期总览、3-5 条趋势、重点关注条目、对你所在行业的启示、风险提示、下期观察点，外加按关注度排序的全部资讯清单（点击可展开）。

**Q：Actions 运行失败（红色叉）？**
点进失败的那次运行看红色步骤的日志。最常见原因：① 密钥名拼错（必须是 `MOONSHOT_API_KEY`）② Kimi 账户没充值 ③ 第 3 步 `.github` 文件夹没上传成功。

**Q：页面打不开？**
第一次开启 Pages 后要等约 5 分钟部署。确认第 6 步已设置、且 Actions 是绿色的。

**Q：想换解读模型/调每天运行时间？**
- 换模型：Settings → Secrets 里改不行，需编辑 `scripts/summarize.py` 顶部 `MODEL`（如 `moonshot-v1-8k` 更便宜）
- 调时间：编辑 `.github/workflows/daily.yml` 里的 cron（注意是 UTC 时间，北京时间减 8 小时）

**Q：费用？**
GitHub 完全免费。Kimi 按 token 计费，每天一份日报约几分钱人民币。
